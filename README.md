# AutoFlow ⚡ (2026 Edition)

An advanced, native Android automation engine built entirely with Kotlin, Jetpack Compose, Material 3 Expressive, Room DB, and Android Accessibility & Notification APIs.

## 🚀 Features

- **Multi-App Triggers & Actions**:
  - **WhatsApp**: Incoming message triggers, direct chat opening, automated text entry & sending, accessibility auto-send.
  - **Telegram**: Notification listeners, direct chat URL/deep-links, Bot API sending, accessibility auto-send.
  - **YouTube & Social**: Video playback control, URL openers, Instagram direct messaging.
  - **Device & System**: SMS triggers/actions, Wi-Fi, Bluetooth, volume controls, notifications, scheduling & interval timers.
- **2026 UI/UX Design**:
  - Material 3 Expressive squircle design system & custom color tokens.
  - Interactive **Hero Dashboard** with live engine health pulse.
  - Visual **Node-Based Flow Builder** (When ➔ Only If ➔ Then Do ➔ Limits).
  - Searchable **App Picker** with original high-resolution app icons and names.
  - Over 33+ ready-to-use automation templates.
  - Real-time execution logs with millisecond latency tracker (⏱ ms).

## 🛠 Tech Stack

- **Language**: Kotlin 2.0+
- **UI Toolkit**: Jetpack Compose + Material 3 Expressive
- **Architecture**: MVVM + Coroutines + Kotlin Flow
- **Persistence**: Room Database + SQLite
- **System Services**: Android AccessibilityService, NotificationListenerService, BroadcastReceivers, WorkManager
